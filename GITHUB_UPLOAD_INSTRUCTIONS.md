# GitHub upload checklist

This folder is the clean repository bundle (about 3 MB). It leaves out the dataset, the cached features (`cache/`,
750 MB), the generated SDXL images (`synth/`, 216 MB), raw logs, and the per-image probabilities of every method
(`results/probs/`, 77 MB). All of them are regenerated by `scripts/run_all.sh`.

## 1. Finalize the report

The report uses the layout of the Assignment 2 report. It prints the repository link in Section 1 and no author
name (`student_name` only goes into the file metadata). Edit `assignment3/report/report_metadata.json`:

```json
{
  "student_name": "Your Name",
  "github_url": "https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY"
}
```

Then rebuild and copy the result into the bundle:

```bash
cd assignment3
conda run -n cv python -m pip install python-docx     # only if not installed; needed for the Word file
conda run -n cv python scripts/build_report.py        # prints "(2 pages)"
cp report/assignment3_report.pdf report/assignment3_report.docx report/report_metadata.json github_upload/report/
```

The PDF embeds Liberation Serif/Sans when the `.ttf` files are installed or placed in `cache/fonts/`; otherwise it
uses the built-in Times/Helvetica with the same layout. Open the PDF once. Check that it has two pages and that the
repository link is clickable. If you edit the Word file instead, export it to PDF yourself and check the page count.

## 2. Verify the bundle

```bash
cd github_upload
(cd checkpoints && sha256sum -c SHA256SUMS)
ln -s /path/to/course/data data                        # local only; data/ is ignored by Git
conda run -n cv python evaluate.py checkpoints/siglip2_so400m_seed0.pt --per-class
rm data
```

Expected: zero-shot 88.75%, inductive **92.00%**, transductive **92.25%**.

## 3. Commit and push

```bash
git init -b main
git config user.name "Your Name"
git config user.email "your.email@example.com"

git add .gitignore requirements.txt src splits extract_features.py extract_synth.py generate.py \
        run_methods.py run_ablations.py ensemble.py finetune_lora.py eval_lora.py scripts/run_all.sh \
        scripts/oracle_probe.py
git commit -m "One-shot pipeline: splits, frozen features, SDXL support sets, CLIP-LoRA, all methods"

git add train.py evaluate.py checkpoints results scripts/summarize.py
git commit -m "Add final one-shot checkpoint, inference script and results"

git add README.md AI_USAGE.md report scripts/build_report.py GITHUB_UPLOAD_INSTRUCTIONS.md
git commit -m "Document results and add two-page report"

git status --short   # should print nothing
git remote add origin https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git
git push -u origin main
```
